Бизнес-логика

Контекст

B2B-сервис 1С-Отчётность. Партнёры — компании, работающие с отчётностью клиентов. Поддержка — критическая точка контакта, скорость ответа напрямую влияет на retention. Бот внедрён во внутренний технический чат поддержки партнёров.

Проблема

  • 70% запросов — рутина (15 минут на тикет)
  • Один сотрудник тратит 24 часа в неделю на повторяющиеся вопросы
  • Масштабирование команды = непропорциональный рост ФОТ
  • Эксперты выгорали → текучка → потеря компетенций → ещё больше нагрузка

Решение

Инициировала проект AI-бота во внутреннем техническом чате. Сама посчитала unit-экономику и защитила бюджет 60 000 ₽.

Логика работы: сотрудник пишет вопрос по сервису 1С-Отчётность → бот отвечает, если знает решение → если не знает или уверенность низкая — зовёт эксперта через @mention → когда эксперт отвечает, бот логирует информацию для дообучения и статистики.

Спроектировала систему с адаптивным порогом уверенности, кэшированием и GDPR-протоколами. Заложила панель статистики для дообучения команды: система показывает темы с высоким процентом эскалаций (например, 40% по платежам) — это основа для точечного обучения. Бот дообучается на разобранных кейсах.
