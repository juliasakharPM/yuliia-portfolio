Бизнес-логика

Контекст

▾

Рынок 3D-проектирования интерьеров фрагментирован. Профессиональные инструменты (3ds Max, SketchUp) дорогие и сложные. Онлайн-решения (Homestyler, Planner 5D) примитивные. Между ними — пустота.

Проблема

▾
  • Дизайнеры тратят часы на рутину (подбор материалов, визуализация)
  • Частные пользователи не могут визуализировать идеи → не покупают
  • Нет связки «проектирование → покупка» → потеря комиссии
  • Образовательный сегмент (вузы, колледжи) не охвачен

Решение

▾

Спроектировала DesignMatrix — облачную платформу с AI-генерацией, 3D-редактором на WebGL, интегрированным маркетплейсом и открытым API. Провела сравнительный анализ стоимости разработки в 4 локациях, заложила 4 источника дохода.

Бизнес-модель

▾
  1. Подписки: Базовая (990 ₽/мес) / Про (2 990 ₽/мес) / Корпоративная (от 9 900 ₽/мес)
  2. Маркетплейс: комиссия 10–15% с продаж материалов и мебели
  3. Партнёрки: интеграция с поставщиками
  4. Реклама: таргетированная от компаний-партнёров
  5. Дополнительно: образовательный сегмент — лицензии для вузов (150–200K ₽/год), подписки для студентов (5–10K ₽/год)

Точки роста

▾
  1. AI-генерация дизайнов → снижение порога входа
  2. Интегрированный маркетплейс → комиссия
  3. Открытый API → интеграция с CAD, CRM, образовательными платформами
  4. Образовательный сегмент → LTV x3–5 vs B2C
  5. AR/VR-визуализация → премиум-функция
  6. Экспорт в проф. форматы (FBX, OBJ, STL, DAE, 3DS) → платная функция для профи
